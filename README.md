# HR Analytics Dashboard (Tableau)

## 📌 Project Overview
This project is an **interactive HR Analytics Dashboard** built in Tableau.  
It is designed to help HR managers analyze workforce data efficiently, offering both **summary insights** and **detailed employee-level analysis**.  

The dashboard provides clear, data-driven visuals to support decision-making around hiring, demographics, and salary structures.  

---

## 🎯 User Story
**As an HR Manager**, I want a comprehensive dashboard to analyze HR data, providing:
- **Summary Views** for high-level insights  
- **Employee Records View** for in-depth analysis  

---

## 📊 Dashboard Features

### 🔹 Summary View
The summary is divided into **Overview, Demographics, and Income Analysis**.  

#### **1. Overview**
- Total hired, active, and terminated employees  
- Hiring & termination trends over the years  
- Employee breakdown by **department** and **job title**  
- HQ vs Branch employee comparison  
- Employee distribution across **cities** and **states**  

#### **2. Demographics**
- Gender ratio of employees  
- Workforce distribution by **age groups** and **education levels**  
- Count of employees within each age group and education level  
- Correlation between **education background** and **performance ratings**  

#### **3. Income Analysis**
- Salary comparison across education levels for both genders  
- Correlation of **age vs. salary** across departments  

---

### 🔹 Employee Records View
- Comprehensive list of all employees with key details:
  - Name, Department, Position, Gender, Age, Education, Salary  
- **Interactive filters** on all columns for detailed exploration
